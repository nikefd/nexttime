# Security Policy

## Supported version

Security fixes target the latest version available through the App Store or TestFlight.

## Reporting a vulnerability

Please report vulnerabilities privately to `nikefd@gmail.com` with the subject
`NextTime security report`. Include a concise description, affected version, and
reproduction steps. Do not open a public issue for an unpatched vulnerability.

Do not include sexual history, medical history, real training records, passwords,
private keys, payment information, or other sensitive personal data in a report.

The project does not offer a bug bounty or guarantee a specific response time, but
good-faith reports will be reviewed and handled as promptly as practical.
