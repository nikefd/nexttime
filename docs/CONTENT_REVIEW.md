# NextTime 专业内容审阅包

状态：**待真实专业人士审阅，不得标记为已完成**  
内容版本：MVP-C-1  
准备日期：2026-10-12

## 目的与范围

请审阅 NextTime 1.3.x 的中英文健康教育、训练引导、安全提示与伴侣沟通内容。产品面向 18 岁及以上成年人，定位为生活方式与健康教育工具，不做诊断、治疗或疗效保证。

适合的审阅人包括：持有效资质的泌尿科或妇科医生、盆底健康物理治疗师，或与所审内容直接相关的合格性健康专业人士。伴侣同意内容可另请具备相关训练的专业人士审阅。

## 审阅材料

- App：onboarding、四条练习路线、7 天计划、状态记录、了解页、伴侣沟通卡和设置页。
- 网站：[首页](https://nikefd.github.io/nexttime-site/)、[安全说明](https://nikefd.github.io/nexttime-site/safety.html)、[资料来源](https://nikefd.github.io/nexttime-site/sources.html)。
- 公开参考资料：网站资料来源页列出的 NIDDK、Cleveland Clinic、NHS、ACOG 与 RAINN 页面。

## 必审清单

- [ ] 练习阶段、持续时间、重复次数与进阶逻辑适合一般成人自助使用。
- [ ] 收缩与充分放松并重，没有暗示“更多、更久一定更好”。
- [ ] 对疼痛、出血、麻木、头晕、排尿/排便困难和症状加重的停止及转诊提示充分。
- [ ] 对孕产期、近期手术、现存症状和盆底过度紧张等情形的边界表述适当。
- [ ] 未把中断排尿建议为日常训练。
- [ ] 未作诊断、治疗、治愈或确定性性功能改善承诺。
- [ ] 伴侣练习遵循清晰、自愿、持续、可撤回的同意原则。
- [ ] 中英文含义一致，普通用户可以理解。
- [ ] 引用来源能支持对应内容，且没有超出来源结论。
- [ ] 需要补充、删改或交由其他专业领域审阅的内容已逐项记录。
