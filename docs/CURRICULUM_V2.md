# 训练整改：单一四阶段课程

2026-11-19，接用户对 TestFlight 1.4.0 的反馈继续整改。本轮本地版本，未发布。

## 已撤下

系统自动音色及设备音色列表、AVSpeechSynthesizer 朗读与兜底、旧18节课程列表、自定义加量入口、进展页旧路线课程分母。旧数据仍保留在历史，TrainingData 只作旧数据名称与历史算法兼容，不再提供训练入口。Pro说明不再销售18节旧课或自定义入口。

语音选择只有默认女声 Xiaoyi 与男声 Yunxi。遇到旧系统音色标识时，设置迁移并保存为默认女声；切换男声仍可持久化。第二至四阶段现已补齐同音色的开场、组间检查与练后回顾。可暂停/恢复、重听或改为阅读；播完后等待准备确认。英文教学仍在屏幕上，动作口令使用所选中文录音，设置已明确标注。

## 新训练内容

| 阶段 | 目标 | 流程 |
| --- | --- | --- |
| 识别与释放 | 区分轻柔收紧和完整松开 | 中文完整录音教学、2次示范、6次主练习；英文使用文字准备与两组主练习 |
| 稳定控制 | 收紧时保持自然呼吸，觉察多余用力 | 配音教学（可改阅读） → 3次动作 → 休息 → 主动检查 → 3次动作 → 回顾 |
| 分组与释放 | 在组间觉察紧张，决定是否继续 | 同等动作量，检查是否回到放松状态；未放松不勉强继续 |
| 独立练习与复盘 | 知道舒适姿势、停止信号和下次重点 | 使用熟悉坐姿或卧姿，不加量，以复盘形成安排 |

后续阶段延用已有样课3秒收紧/6秒释放的示意窗口，不延长强度。每次两组各3次，组间20秒休息，结束25秒休息，动作与休息共99秒；阅读、组间确认和回顾的等待不计时。组间必须主动确认，不自动跨过。完整释放结束才累计一次，记录实际次数、组数和课程版本。阶段不是临床能力等级，课程参数仍待男性盆底专业审阅。

首页只启动当前阶段，列表入口改为四阶段安排预览，不提供跨阶段随意加练入口。第一阶段免费，后续保持既有Pro限制，本轮没有改变购买状态或价格。

## 休息与进度

报告低精力、紧张或不适后，首页显示休息与状态建议，不再用旧呼吸/身体扫描计时课代替训练。持续/反复不适及警示症状仍进入既有专业评估建议。休息不会抹去进度。

新版阶段计数要求匹配路径、阶段、课程和支持的课程版本；已发布第一阶段录音版的记录继续有效。旧无版本课程留在历史但不计新版完成数，不把旧课改名后当作新课完成。当前路径位置不被擅自重置。练后反馈仍按记录绑定，不确定不进阶，不适接入安全逻辑。

## 指导依据与边界

2026-11-19通过ego-browser重新核对 [NHS男性盆底指导](https://dynamichealth.nhs.uk/help-and-advice/pelvic-health/pelvic-floor-exercises-for-men/)，采用保持正常呼吸、收缩后完整放松、质量优先的教学原则。来源并未验证本App的四阶段结构、99秒流程、进阶阈值或性健康疗效；这些是待专业审阅的产品安排。

## 验证

36项单元测试通过，覆盖双音色资源、旧音色迁移、四课结构、释放后计数、版本记录、旧课程不计新版进度、反馈与阶段限制。6项UI流程分组通过：双音色选择持久化与无系统选项、后台暂停、新第二阶段真实99秒练习与反馈、全阶段免费预览及旧课入口移除、主动回顾/Pro限制/重启持久化、低精力休息页不启动替代训练。休息页首轮测试因调试种子未正确设低精力而失败，修正种子后复测通过。本地化文件及git diff检查通过。

## 后续配音接入

第二至四阶段三段不同开场、共用检查与回顾，男女声共10份新录音；实际配音与练习约151–153秒，用户准备等待另计，动作/休息仍99秒。关闭语音时直接显示可阅读的准备说明，不再等待静音讲解。资源来源与校验记录见本次聊天交付包的audio/provenance.json。具体实现见[CURRICULUM_NARRATION.md](CURRICULUM_NARRATION.md)。
