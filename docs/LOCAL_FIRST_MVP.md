# NextTime 本地优先成人性健康 MVP

状态：里程碑 A、B 已完成；里程碑 C 待实现
日期：2026-10-12
目标版本：1.3.0

## 1. 产品定位

**一句话定位：** 面向成年人的私密盆底训练与亲密健康助手，通过循序渐进的身体训练、放松练习、科学科普和伴侣沟通练习，帮助用户建立更健康、更有信心的亲密生活习惯。

产品属于成人健康与生活方式工具，不提供诊断，不替代医生或治疗师，不承诺治愈勃起障碍、早泄、疼痛或其他疾病。

### 目标用户

- 18 岁及以上成年人。
- 希望改善盆底控制、身体觉察、亲密信心或伴侣沟通的人。
- MVP 以个人使用为主，同时提供可在同一设备上完成的伴侣练习。
- 不强制填写性别、性取向、性生活频率或具体病史。

### 核心原则

1. 默认离线，敏感数据不离开设备。
2. 不注册、不登录、不建立云端用户画像。
3. 不使用广告、第三方行为分析或通用 AI 聊天服务。
4. 功效文案使用“练习、支持、可能有助于”，不使用“治疗、治愈、保证、延时多少分钟”。
5. 安全提示、删除数据和基础训练不得设为付费功能。

## 2. MVP 用户旅程

### 首次启动

1. 成人确认：用户确认已满 18 岁。
2. 安全说明：产品不是医疗诊断或治疗工具；出现疼痛、出血、麻木、突发或持续严重症状时应停止练习并咨询专业人员。
3. 隐私说明：所有训练与自评数据仅保存在当前设备，可随时删除。
4. 目标选择，可多选：
   - 建立盆底基础
   - 学会收缩与充分放松
   - 提升身体觉察与亲密信心
   - 改善伴侣沟通与亲密感
5. 根据目标生成首个 7 天入门计划；用户也可跳过目标选择直接使用基础训练。

### 日常使用

1. 首页显示今日建议练习和预计时长。
2. 可选的练习前状态记录：舒适度、紧张度、精力，均为 1–5 档。
3. 完成语音、震动和屏幕引导练习。
4. 可选的练习后反馈：是否舒适、是否出现不适、主观放松程度。
5. 本地更新连续练习、完成率和趋势，不产生云端事件。

## 3. 信息架构

沿用现有五个 Tab，降低改造成本。

### 今日

- 今日练习卡
- 7 天计划进度
- 一分钟状态记录
- 通用、隐蔽的提醒设置
- “出现不适怎么办”安全入口

### 练习

MVP 提供四条路线：

1. **基础控制**：肌肉识别、短收缩、耐力、协调。
2. **放松恢复**：腹式呼吸、盆底放松、避免过度收紧。
3. **信心与觉察**：呼吸节奏、身体扫描、表现焦虑降级练习。
4. **一起练习**：伴侣沟通卡、欣赏表达、边界与同意、非露骨亲密练习。

现有 14 个训练不全部删除，但需要重新审查强度、命名和进阶逻辑。尤其避免把更多、更久的收缩简单等同于更好；放松与恢复必须成为正式课程。

### 进展

- 完成次数、练习分钟、连续天数
- 四条路线的完成度
- 舒适度、紧张度和放松程度的本地趋势
- 不展示“性能力分数”或与他人的排名

### 了解

- 盆底肌基础
- 收缩与放松同样重要
- 压力、睡眠、运动与亲密状态
- 伴侣沟通、同意和边界
- 什么时候应该咨询医生或盆底康复专业人员
- 内容来源与审阅人说明

### 设置

- 语音、震动、提醒和隐私模式
- Face ID/Touch ID 应用锁（如设备支持）
- 通知文案隐私开关，默认显示“该进行今日练习了”
- 导出个人数据，MVP 可后置
- 一键删除所有数据
- 隐私政策、使用条款、支持和医学免责声明

## 4. 功能优先级

### MVP 必须完成

- 成人、安全和本地隐私 onboarding。
- 四条训练路线及 7 天入门计划。
- 收缩、放松、呼吸、静息四种训练阶段。
- 可选的练习前后状态记录。
- 本地进展趋势。
- 同设备伴侣沟通卡，不建立伴侣账号。
- 生物识别应用锁和隐蔽通知。
- 完整的数据清除能力。
- 中英文内容和无障碍基础支持。
- 现有 GitHub Pages 官网、隐私政策、使用条款和支持页面可访问。

### 可以稍后加入

- 经用户主动操作的加密本地导出/导入。
- Apple Watch 引导。
- HealthKit 只读或写入。
- 订阅制内容库。
- 经专业人员审阅的标准化自评量表。

### MVP 明确不做

- 云账号、跨设备同步和伴侣远程配对。
- AI 性健康顾问或聊天机器人。
- 社区、匿名聊天、UGC 图片或视频。
- 露骨器官图像、色情故事或刺激性内容。
- 通过摄像头、麦克风或手机传感器测量性功能。
- 医疗诊断、药物推荐或确定性疗效承诺。
- 广告、用户画像和第三方行为分析。

## 5. 本地数据设计

### 数据模型

- `WellnessPreferences`：目标、提示和隐私偏好。
- `PracticePlan`：入门计划和当前进度。
- `PracticeSession`：课程、时长、完成状态和时间。
- `WellnessCheckIn`：练习前后舒适度、紧张度、精力与是否不适。
- `ContentProgress`：文章与沟通练习完成状态。
- `SafetyAcknowledgement`：用户确认过的安全说明版本。

### 存储策略

- `UserDefaults` 只保存非敏感 UI 设置，例如语音、震动和主题。
- 训练、自评和亲密健康记录保存到受 iOS Data Protection 保护的本地数据库。
- 敏感数据库使用 `NSFileProtectionComplete`，密钥或锁定状态保存在 Keychain。
- MVP 不使用 CloudKit、iCloud 同步或服务器备份；敏感数据文件排除出 App 自建的云端同步流程。
- 日志、崩溃信息和调试输出不得包含自评答案或健康记录。
- 用户删除数据后应同时清理数据库、缓存和通知。

## 7. 商业化建议

MVP 保留目前的一次性 Pro，比立刻改订阅更稳妥。

### 免费

- 成人与安全 onboarding
- 7 天基础计划
- 基础控制和放松练习
- 安全科普与数据删除
- 基础进展统计

### Pro

- 完整四路线课程
- 自定义练习
- 详细本地趋势
- 更多伴侣沟通卡
- 高级提醒和隐私设置

只有在形成持续更新的专业内容库后，再评估订阅制。所有数字功能继续通过 StoreKit 销售。

## 8. 内容与审核规则

### 推荐用语

- “支持盆底控制与放松训练”
- “帮助建立更健康的亲密习惯”
- “可能有助于改善身体觉察与信心”
- “结果因人而异”
- “如症状持续或影响生活，请咨询专业人员”

### 禁止用语

- “治愈阳痿/早泄”
- “保证增强勃起”
- “训练七天延时 X 分钟”
- “替代医生或药物”
- “医学认证”——除非确有可验证的监管或专业认证

课程内容发布前应由泌尿科、妇科、盆底康复或合格性治疗专业人士审阅，并记录审阅人、日期、来源和内容版本。

## 9. 官网与后端策略

MVP 继续使用现有 GitHub Pages：`https://nikefd.github.io/nexttime/`，暂不迁移到 Hetzner 或 `zhangyangbin.com`，也不需要业务 API。

GitHub Pages 承载以下静态页面：

- `/`：产品介绍
- `/privacy`：隐私政策
- `/terms`：使用条款
- `/support`：支持与联系方式
- `/safety`：安全说明和就医提示
- `/sources`：课程资料来源与审阅信息

网站不应加载广告像素或行为追踪器。发布前应确保 Apple 审核期间所有 GitHub Pages 链接稳定可访问。

Hetzner 服务器和 `zhangyangbin.com` 保留给后续阶段；只有确定需要账户、受控内容后台或其他动态服务时再单独设计。即使未来启用，也不默认上传敏感健康数据。

## 10. 验收标准

- 首次启动必须完整展示成人、安全和隐私说明。
- 所有核心训练在飞行模式下可用。
- 抓包验证 App 不上传训练、自评或伴侣练习数据。
- 用户拒绝通知、生物识别或状态记录后，基础功能仍可使用。
- 一键删除后无法在 App 内恢复敏感记录。
- 通知锁屏文案不暴露性健康主题。
- VoiceOver、动态字体及中英文布局可完成核心流程。
- 单元测试覆盖计划生成、数据迁移、删除和训练状态机。
- UI 测试覆盖 onboarding、完成训练、记录反馈和删除数据。
- TestFlight 审核备注说明成人健康定位、非医疗用途、本地数据策略及测试路径。

## 12. MVP 成功信号

在不收集服务器行为数据的前提下，通过 TestFlight 访谈和可选问卷判断：

- 用户能否在没有额外解释的情况下正确完成首次练习。
- 用户是否理解“收缩和放松同样重要”。
- 用户是否信任本地隐私设计。
- 7 天计划是否容易坚持。
- 伴侣沟通卡是否自然、不尴尬且没有露骨感。
- 是否存在不适、过度训练或误解医学功效的反馈。
