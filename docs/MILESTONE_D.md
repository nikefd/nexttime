# 里程碑 D：引导练习与隐蔽体验升级

更新日期：2026-10-12

## 目标

解决两个体验问题：课程不再只是换参数的倒计时；隐私模式不再用动作颜色、动作名称和剩余秒数暴露训练主题。

## 已实现

- `GuidedPracticeStep` 脚本模型：支持说明、呼吸、收缩、放松、身体扫描、反思、伴侣提示与休息。
- 四条路线拥有不同的脚本结构和引导内容，而非共用“收缩—放松”外壳。
- 阅读与沟通步骤由用户主动继续；计时步骤保留克制的时间提示和语音/触觉反馈。
- 旧的自定义课程及未迁移预设可自动转换为兼容脚本。
- 隐蔽练习模式只显示“进行中/暂停/完成”和整体进度。
- 暂时显示详细内容 8 秒后自动重新隐藏。
- App 进入非活跃或后台状态时显示中性遮罩，避免任务切换器快照泄露内容。
- 删除循环静音音频保活实现。

## 验收

- 基础路线包含真实的收缩与放松循环。
- 放松路线包含呼吸、身体扫描和释放步骤。
- 信心路线包含非评判身体扫描与反思。
- 伴侣路线包含明确同意、可跳过提示、倾听或边界表达步骤。
- 隐蔽模式不显示课程名、动作、性健康主题或剩余秒数。
- 中英文 `.strings` 文件通过格式检查。
- 单元测试覆盖脚本差异、旧课程兼容和计时长度。

## 尚未替代的人工作业

这些引导内容属于待审阅草案，仍需由可验证的盆底康复、泌尿/妇科或合格性健康专业人士审阅。里程碑 D 的完成只代表产品与工程体验升级，不代表专业审阅或功效验证已经完成。

## 语音自然度优化

根据 TestFlight 反馈，后续又完成以下改进：

- 自动优先选择设备已安装的 premium/enhanced 高质量音色。
- 中文与英文分别使用接近日常说话的语速，轻微降低长段引导音高并加入句前、句后停顿。
- 3–8 秒的收缩/放松阶段只播报简短口语提示，不再朗读整段屏幕说明。
- 移除短收缩阶段的语音倒数，避免不断打断提示。
- 步骤切换改为在词语边界结束当前播报；退出训练仍立即停止。
- 设置页支持声音选择和“试听自然引导”，并继续尊重用户的语音与音量设置。
