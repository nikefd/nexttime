# 里程碑 E：本地个性化与安全闭环

更新日期：2026-10-12

## 目标

让练习前后的状态记录真正影响下一步，同时在用户出现不适时形成“停止—恢复指引—后续推荐调整”的本地闭环。所有规则都在设备上计算，不上传敏感数据，也不推断疾病。

## 推荐规则

- 今日舒适度不高或紧张度较高：切换到温和呼吸与放松。
- 今日精力较低：切换到无强度目标的身体扫描。
- 近 7 天有一次普通不适：优先恢复，只推荐温和呼吸。
- 近 14 天累计多次普通不适：提示考虑咨询医生或盆底康复专业人员。
- 近 14 天记录疼痛、出血、麻木或突发/明显症状：暂停今日快捷练习并提示及时寻求专业评估。
- 没有触发调整：继续用户目标生成的 7 天计划。

这些规则只影响首页快捷推荐，不锁死“练习”列表，也不声称能识别或治疗疾病。

## 训练中安全流程

1. 正常训练页和隐蔽模式始终保留停止入口。
2. 用户可选择“轻微不适或紧张”或“警示症状”。
3. 系统立即停止训练并保存未完成记录。
4. 普通不适显示呼吸、舒适姿势和当日不再增加强度的建议。
5. 警示症状提示停止训练、寻求专业评估；严重或迅速加重时联系当地急救服务。
6. 安全事件写入受文件保护的本地存储，并参与后续推荐。

## 隐私与边界

- 不记录自由文本症状、诊断、位置或联系人。
- 不向服务器、分析服务或第三方上传安全事件。
- 一键删除会同时删除安全事件。
- 进展页只显示日期、分流结果和近 14 天事件数量。
- 内容仍需里程碑 C 中的真实专业审阅；工程规则不构成医学验证。
