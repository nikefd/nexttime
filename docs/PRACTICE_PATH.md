## 用户行为

首页显示当前阶段、本阶段已完成路径练习次数、下一阶段及完整路径入口。进展页也可进入同一条路径，免费用户可预览全部阶段。学习阶段与训练量、肌力或性功能改善分开展示；不显示能力改善百分比。

路径依次为识别与释放、稳定控制、节奏与释放、巩固与日常应用。对应 foundationAwareness、foundationCoordination、foundationSteadyControl、foundationDailyTransfer。第一阶段中文预制双音色已接入实际训练：两次示范、六次主练习和练后反馈；其他阶段仍使用已有课程。整套内容尚未完成专业审阅或全部重录；设置中的独立试听始终不计入训练。

完成当前阶段的路径练习后，可以主动回顾是否自然呼吸、完整释放、没有不适。三项默认均未确认；不确定可取消、继续当前阶段。App没有生理传感器，回顾是用户的学习自评，不是能力测量或医学评估。阶段前进不是自动处方，也不代表已掌握。下一课程会显示具体名称，免费/Pro限制继续生效。

## 进度口径

- 新路径拥有独立UUID、创建时间、当前阶段、阶段进入时间及自评历史。
- 首页主路径开始的训练才附带路径UUID与阶段。安全调整后的支持练习、自选课、试听没有这一上下文。
- 本阶段计数仅包含相同路径、相同阶段、相应课程、完整完成、实际计时大于零、在阶段开始后且不晚于当前时间的记录。
- 路径不按注册日或自然日移动，不因同日多练、重复课程或第43天自动进阶。
- 原有记录继续显示在历史中，不回填路径字段、不删改、不算新阶段已完成。
- 回顾确认必须关联当前阶段最近一次有效完成记录。再次提交旧阶段回顾、未勾选全部自评、无有效完成记录，都会被拒绝。
- 提交时重新读取当前路径与安全状态。近期开启安全降级或今日需要调整时，保留当前阶段；不通过旧页面绕过新反馈。
- 保存阶段失败时不会在界面假装已成功。记录写入成功后才标记课程完成或发出完成回调。
- 清空所有数据同时清除路径状态，重新开始不混入旧路径记录。

## 兼容与边界

TrainingRecord新增可选pathID/pathStage及lessonVersion/completedRepetitions/totalRepetitions，旧JSON无需这些字段。状态与学习回顾继续写入现有保护存储，不上传。训练阶段的实际保存由TrainingManager携带开始时的上下文完成，列表等其他入口默认无上下文。

旧的sixWeekPlan/longTermRecommendation函数作为历史兼容与回归样例保留，但产品界面不再调用；当前首页和路径页都以PracticePathState为准。后续清理历史API时须同步其测试，不能重新将它接回首页。

第一阶段新播放器的反馈按完成记录ID保存且不可覆盖，避免事后把不适改成舒适来绕过安全规则。新课程记录缺少反馈或反馈不确定/不适时，不能进入阶段回顾；路径页提供补填入口。旧记录继续保持兼容。未重做全部18节内容，也未将学习自评阈值作为临床验证的进阶标准。

## 验证范围

单元测试覆盖长期未练不升级、旧记录/自选记录/未完成/零秒/未来记录不计入阶段、重复练习不自动升级、明确回顾才移动、旧回顾不可重复提交、安全反馈阻止移动、路径清空、旧记录解码与训练管理器写入真实路径上下文。
