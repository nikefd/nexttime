# NextTime 项目检查与体验修复

本次依据当前源码检查训练流程、购买与恢复、页面导航、本地存储、提醒设置、应用锁以及 CI/发布配置。不是医学内容专业审阅，也不是完整渗透测试。

## 本轮修复

- **Pro 统计入口缺失**：在进展页恢复详细统计入口，免费用户进入权益页，Pro 用户直接查看图表。
- **商品价格误导**：移除商品未加载时写死的 ¥25。价格不可用时禁止购买并提供重新加载入口；购买、恢复失败和待批准状态使用中英文提示。
- **权益失效未同步**：每次刷新依据 StoreKit 当前有效权益重新计算 Pro 状态，交易更新也触发刷新，避免退款后永久保持旧缓存。截图用 DEBUG 状态单独隔离。
- **训练时长虚高**：记录实际计时阶段累计秒数，排除暂停和等待阅读说明的时间；保留停止后不重复保存记录的行为。
- **确认对话框期间仍继续训练**：打开退出或不适对话框时暂停计时、震动与播报。取消后由用户主动继续。
- **当天状态被默认值覆盖**：重新进入状态调整时回填当天最近一次保存的评分。
- **旧记录迁移风险**：只有目标写入成功才删除旧记录；解析/写入失败保留来源并允许重试。保护存储退回内存模式时，不迁移并删除持久化旧记录。

## 后续优先事项

本轮验证：22 项单元测试全部通过；可选课程列表、今日进阶课程付费拦截、详细统计免费/Pro 访问共 3 项 UI 测试通过。新增统计入口测试的首轮标题断言错误已修正并重跑通过。中英文本地化格式与差异检查通过。未执行真实付款、退款或真机锁屏测试。

1. 真机验证简短口令、震动、暂停恢复、锁屏与应用切换；目前后台计时仍依赖 Timer，系统挂起时不能保证节奏连续。
2. 使用 StoreKit 沙盒实测首次购买、退款、恢复、待批准及离线有效权益；本轮源码修复不等于已完成真实交易验证。
3. 提醒授权失败应回退开关并提供系统设置入口；当前提醒设置仍忽略部分调度失败返回值。
4. 将敏感数据写入/删除错误明确呈现给用户。目前部分保存使用 `try?`，保护存储异常时也存在内存降级路径，后续需统一设计错误与重试体验。
5. 自选课与自定义训练应复用首页的安全暂停决策；当前本轮未调整推荐规则或临床参数。
6. 发布新版本时更新商店截图并复核买断文案；本轮没有提交 App Store 或改变商品价格。

这些后续事项是代码检查发现的工作项，不代表已验证发生在用户设备上。语音调整尚需随下一版 TestFlight 发布。
