Privacy

隐私政策

生效及最后更新：2026 年 10 月 12 日

简要说明：无需账户；训练、自评与伴侣练习记录保存在设备本地；开发者不接收这些记录；无广告、第三方分析或跨 App 跟踪。

我们不收集什么

下一次不要求注册或登录。App 不向开发者服务器上传姓名、联系方式、训练记录、自评、目标或伴侣沟通内容，也不使用广告 SDK、第三方行为分析、HealthKit、位置、相机或麦克风。

设备上的数据

训练历史、计划、自评和安全确认保存在受 iOS Data Protection 保护、且排除在设备备份之外的本地数据库中。非敏感界面偏好保存在系统偏好存储中。App 不提供 CloudKit 或自建云同步。

你可以在“设置 → 数据 → 清除所有数据”删除 App 内保存的记录。卸载 App 通常也会删除其本地容器；Apple 对设备与购买记录的处理受其自身政策约束。

系统服务与权限

  • 通知：仅在你主动开启提醒后使用；隐蔽通知默认不显示盆底主题。
  • Face ID / Touch ID：可选，仅由 iOS 完成验证；App 不接收生物识别模板。
  • App Store：购买由 Apple 处理。开发者不会收到完整支付卡信息；Apple 可能向 App 提供购买状态。

网站

本官网托管于 GitHub Pages，不嵌入广告像素、分析脚本或表单。访问托管页面时，GitHub 可能按其政策处理必要的服务器日志；请参阅 GitHub 隐私声明。

年龄与变更

本服务仅面向 18 岁及以上成年人。若数据实践发生实质变化，我们会更新本页及日期，并在需要时通过 App 说明。

联系

隐私问题可发送至 nikefd@gmail.com。请勿在邮件中发送具体性行为、病史或其他敏感健康信息。
